# Phishing Awareness Training

## 📌 Project Overview

This project is a phishing awareness training presentation.

The presentation helps users understand phishing attacks, recognize suspicious messages and fake websites, and follow safe practices to reduce phishing risks.

## 🎯 Objectives

- Understand what phishing is
- Learn how phishing attacks work
- Identify common types of phishing
- Recognize warning signs in phishing emails
- Identify suspicious or fake websites
- Understand social engineering tactics
- Learn phishing prevention best practices
- Test knowledge through an interactive quiz

## 📚 Topics Covered

1. What is Phishing?
2. How Phishing Attacks Work
3. Common Types of Phishing
4. Warning Signs of Phishing Emails
5. How to Identify Fake Websites
6. Social Engineering Tactics
7. Real-World Style Scenario
8. Interactive Quiz
9. Prevention and Conclusion

## 🛡️ Safety Tips

- Think before clicking links.
- Verify unexpected requests independently.
- Never share passwords through suspicious messages.
- Enable Multi-Factor Authentication (MFA) where available.
- Keep software and browsers updated.
- Report suspicious messages to the appropriate organization.
